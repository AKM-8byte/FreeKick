Bu klasördeki yedi WAV dosyası bu oyun için özgün olarak sentezlendi.
Harici kayıt, lisanslı müzik veya başka bir oyundan alınan ses içermez.

- step: çim üzerindeki krampon adımı
- kick: ayağın topa teması
- bounce: zemin / baraj / kaleci teması
- post: metal direk rezonansı
- net: file hışırtısı
- goal: kısa, sentezlenmiş seyirci tepkisi
- ambience: uzaktaki tribün uğultusu

Üretim: `python tools/generate_audio.py` (Python standart kütüphanesi).
